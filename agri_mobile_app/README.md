# Farm Manager Flutter App

视觉基准：`../docs/ui/flutter-app-concept/index.html`

## 运行

```bash
flutter run
```

本机 Android 调试使用 `bash deploy/flutter-android.sh`（在仓库根目录运行）。
模拟器默认连接 `http://10.0.2.2:9876/api/v2` 和
`http://10.0.2.2:8000/api/v2`。`10.0.2.2` 是 Android 模拟器访问电脑
`127.0.0.1` 的专用地址，不需要端口转发，也不受局域网 IP 变化影响。
App 未传编译参数时，Android 同样默认使用该地址，其他平台使用 `127.0.0.1`。
USB 真机使用 `DEVICE_ID` 指定设备，脚本会改用 `127.0.0.1` 并建立 `adb reverse` 转发。
连接远程后端时，通过 `BUSINESS_API_URL`、`AGENT_API_URL` 覆盖默认地址。

## 全页设计与验收

- 白底、品牌蓝、16–24 圆角和轻边框贯穿登录、注册、首次设置、首页、记录、芽芽、账本和我的。
- 记录页围绕记账、农事、工资组织工作台，资料管理作为次级操作；芽芽入口进入实际聊天流程。
- 芽芽采用开放式话题入口、正文式回复和多行输入区，支持快捷提问、历史对话、技能搜索、详情和执行确认。
- 茬口、模板、工人列表和新增/编辑表单，以及分类管理、交易列表/详情、地区/日期选择、回答风格和关于页面沿用相同组件规范。
- 首页作业、未结工资、账本和管理列表来自真实接口；没有数据时提供空状态，不使用样例经营指标。
- 主导航：首页 / 记录 / 芽芽 / 账本 / 我的。列表支持真实搜索和筛选；无功能的装饰性按钮已移除。
- 账本突出年度净收益与收支摘要，最近流水按日期分组并可直接查看详情；记账按钮带明确文案。规则生成的提示标为经营提示，不再显示仅根据最近记录计算的全年装饰曲线。
- 全页布局回归覆盖 25 个页面，分别使用 390 常规屏幕与 320 窄屏、1.3 倍字号；同时检查页面导航、弹窗、保存、重复提交防护和失败重试。
- 核心页面、认证页、记录确认流程保留截图基准；模拟器截图用于检查真实中文字体和键盘弹出后的布局。

## 后端能力边界

当前 v2 后端尚未提供独立的智能填写解析、移动端版本检测和技能列表接口。
记录页的智能整理直接引导进入芽芽对话；关于页通过系统读取已安装版本，技能页保留本地场景说明，提问示例可直接发送到芽芽。
这些界面不会伪造后端已在线或保存成功的反馈。
